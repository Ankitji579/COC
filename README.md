# Defense Command

A complex browser-based strategy/base-defense game.

## Tech Stack
- **React**: UI overlay and state management (via Zustand)
- **Phaser 3**: High performance WebGL/Canvas game rendering and simulation
- **EasyStar.js**: A* Pathfinding for enemy AI
- **Vite**: Fast build tool

## How to run locally
1. Install dependencies: \`npm install\`
2. Start dev server: \`npm run dev\`
3. Open http://localhost:5173

## How to build for production
\`npm run build\`
The output will be in the \`dist\` folder.
